## 第一次使用

老师会发给你一个压缩包，解压后按你的系统运行一次：

- **Windows** → 双击 `setup-windows.bat`
- **Mac / Linux** → 在终端里执行 `bash setup-mac-linux.sh`

它会自动配好你的专属密钥，并把仓库下载到本地。**只需运行一次。**

## 怎么提交作业

以后每做完一题，在仓库目录里执行：

```bash
git add .
git commit -m "week01: 完成 ex01"
git push
```

**push 成功就算提交**，老师会直接看仓库里的最新代码。

> 不习惯命令行的话，直接用 VS Code 打开这个文件夹，在「源代码管理」面板里点提交和推送也一样。
